# Voice holds

Drafts and visuals that failed a voice check (`settings/voice.md`, `brand/identity/tone-rules.md`) or a visual spec check (`brand/visuals/specs.md`). A held item is never quietly fixed and sent.

What to do with each item:

1. Open the file and read the failing line.
2. Either fix the file yourself (or ask for a revision, which becomes a new `-r2` file) and tick **fixed, release it**, or tick **discard**.
3. Ask the director to process approvals. "Fixed, release it" sends the item back through the approval gate; it does not ship straight away. "Discard" drops it and logs why.

Only you tick boxes. Agents add items to **Open**; the director moves decided items to **Closed**.

## Item template (copy, do not tick)

```
### V-YYYYMMDD-NN | <short title>
- [ ] fixed, release it
- [ ] discard
- Rule broken: "<exact rule, quoted>" (<file it comes from>)
- Failing line: "<the exact line from the draft>"
- File: <work/... path>
- Asked by: <agent>, for <B-YYYYMMDD-NN>
- Owner comment:
```
