## When a post takes off

A post takes off when it passes the breakout threshold in `brand/metrics/kpis.md`. Then:

1. The analyst lists it as a repurpose candidate.
2. The owner or the director runs `/post-breakout`.
3. The scheduler writes versions for other channels, each re-checked, and prepares a boost with the amount left blank.
4. Nothing is boosted until the owner ticks it.

## Never

- Never post the same text unchanged on more than one channel on the same day.
- Never put a link where a channel's rule above says no.
- Never use hashtags on a channel unless `brand/channels/hashtags.md` allows them there.
