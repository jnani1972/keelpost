# Review process

Who approves replies, who hears about problems, and how to invite satisfied customers to leave a review. The reputation agent follows this file; the owner makes every call it lists.
How to use: name a person (by role) and a response time for each row. Asking for reviews means messaging people, so every request waits for the owner.
