# FAQ

The only answers the inbox agent may send. It copies the approved answer word for word; if a question is not here, it sends the holding reply and lists the question as a gap for you.
How to use: one row per question, with the ways people actually ask it under "variants". Set "last checked" every time you confirm an answer is still true; prices and dates go stale fast.

## How to fill

1. Write the approved answer exactly as you want it sent. The agent will not reword it.
2. Put prices, discounts, refund terms and dates only in answers you are happy to send to anyone, any time.
3. Give each row an id from its topic: ORD-, PRD-, PRC-, HRS-, RET-.
