# Keywords and owning pages

Which search terms matter, and which page on your site owns each one. One keyword, one owning page: two pages chasing the same keyword compete with each other.
How to use: group keywords into clusters and give each cluster one owning URL. search-watch may add rows to the gaps table with status `suggested`; you decide what happens to them.
