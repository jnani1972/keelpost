# Search targets

How to use: one row per page that matters. Update the latest position and checked date from the rank tracker export when you review monthly; agents only suggest updates in their reports.

## Labels

- **on target**: latest position is at or better than the target.
- **behind**: worse than target, but not a drop by `brand/search/thresholds.md`.
- **dropped**: counts as a ranking loss by `brand/search/thresholds.md`.
