# Brief layouts

The shape the writer fills in before drafting a word. A filled layout sits at the top of every draft, so you can see what the piece was trying to do.
How to use: keep the shared fields as they are; adjust each channel's layout and length to what works for you. If a length here differs from `brand/channels/channel-rules.md`, channel-rules wins.

## Fields every layout has

| field | what to write |
| --- | --- |
| audience | who this piece is for, in one line, from `settings/strategy.md` |
| promise | the single thing the reader gets from it |
| proofs | three facts that back the promise, each with its proof id or source file |
| keyword | the assigned keyword from `brand/search/keywords.md` (search pieces), else none |
| call to action | one next step, from the calls-to-action table in `brand/identity/claims.md` |

## Per channel

### Article (blog)

- Length: {{fill: e.g. 800 to 1,400 words}}
- Shape: title with keyword; intro of 2 to 3 sentences naming the problem; 3 to 5 subheadings; one subheading contains the keyword; closing call to action.
- Also: meta description of 155 characters or fewer; SEO checks from `brand/content/seo-checks.md`.

### LinkedIn

- Length: {{fill: e.g. 120 to 220 words}}
- Shape: opening line that stands alone; short paragraphs of one or two sentences; one proof; one question or call to action.

### Instagram

- Length: {{fill: e.g. caption 60 to 150 words}}
- Shape: opening line under 10 words; caption that adds to the image, not repeats it; hashtags from `brand/channels/hashtags.md`.
- Also: on-image text for the designer, 8 words or fewer.

### Facebook

- Length: {{fill: e.g. 40 to 120 words}}
- Shape: plain opening; one useful point; call to action; link at the end if allowed.

### Newsletter (email)

- Length: {{fill: e.g. 250 to 450 words}}
- Shape: subject line under 50 characters; preview text; one main story; one secondary item; one call to action.

### Local-listing post (google-profile)

- Length: {{fill: e.g. 60 to 150 words}}
- Shape: what, when, where; one call to action using the listing's button; no hashtags.
