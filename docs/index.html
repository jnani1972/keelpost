Keelpost

A crew of ten Claude Code agents that plans a small business's week of marketing, drafts every post and reply, and ships only what the owner's written rules allow. Everything else waits in one file the owner ticks.

How it works

Every rule, setting, brief, draft, approval and log line is a Markdown file in the project. The owner writes the settings once. Each week the owner drops tool exports into data/ and runs one command.

  1. Gathernewest dated exports, calendar, posting slots
  2. Rankscore jobs on urgency, fit, evidence
  3. Briefone brief per job, written by the director
  4. Producespecialists draft into work/
  5. Scheduleonly what passed every check
  6. Approvethe owner ticks the rest
director

Ranks the week, writes briefs, applies the approval gate. Never drafts or posts.

writer

Drafts posts, articles and emails from project facts only.

designer

Plans visuals and video, checks them against your specs.

scheduler

The only agent that books posts, and only approved ones.

reputation

Drafts review replies. Negative ones always wait.

inbox

Answers messages with approved words, records leads.

search-watch

Rankings, queries and crawl problems, with actions.

rival-watch

Competitor moves and promotions, look-only.

analyst

KPIs, cost per result, spend against caps.

setup-check

Finds missing files and unanswered settings.

The rules it cannot break

Settings can add to this list. Nothing can remove from it. These always go to approvals/pending.md:

Money

Any ad, boost, paid placement or budget change. Spend past a cap is marked OVER LIMIT and never ships.

People

Replies to unhappy reviewers, anything naming a real person, and any message to someone who never wrote first.

Facts

Anything with a [CHECK] marker: a fact that can't be traced to a project file. Prices, offers and dates too.

One empty file, settings/PAUSE, stops every agent until the owner deletes it.

One brief per job

Each brief says why now, what to make, which files to read and what to hand back. Specialists only ever work from a brief.

The gate holds what isn't proven

Nothing shipped this week. The demo brand files had no real proof rows, so the director held every post and wrote down why. A missing brand font failed the visual's spec check.

Install

You need Claude Code. Nothing else to install. REA, for competitor page checks, is optional and starts through npx.

git clone https://github.com/jnani1972/keelpost.git
cd keelpost
claude

/setup-check      # what's missing or unanswered
/weekly-run       # plan, brief, draft, gate

Fill settings/ first: agents refuse to start while any answer is still a placeholder. Then tick approvals/pending.md and ask: “Use the director agent to process approvals.”
